# Security policy

Citoya helps students find volunteer work and log their service hours. Some of those students
are 13 to 17, so a report about how the service handles their data is the most useful thing
you can send.

## Reporting a problem

Email **support@citoya.com** and start the subject with "Security". Say what you found, how to
reproduce it, and what data or accounts it could reach.

Please don't open a public GitHub issue for it. Don't access, change or keep anyone else's data
beyond the minimum you need to show the problem, and don't run automated scanners against
citoya.com services.

## Scope

This file ships with the public mirror of Citoya's frontend and engineering docs. The backend's
source is private, but the running service is still in scope: reports about the published code,
or about any citoya.com service, are welcome.
